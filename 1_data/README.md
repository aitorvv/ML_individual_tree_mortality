## :file_folder: Folder Content


- :sunny: WorldClim data required must be downloaded from its [official website](https://www.worldclim.org/data/index.html)

- :open_file_folder: ***1_raw***: initial tree and plot datasets
  
  - :open_file_folder: ***0_raw*** contains:
    - :open_file_folder: ***Thinning_grade*** contains details about thinning grades
    - :open_file_folder: ***VF_daten*** contains the original data regarding tree inventory. The data is organised in folders corresponding to each experimental area; in each folder, each file contains the inventories of a different plot
    - :floppy_disk: ***Fi-Daten__age.xlsx*** is plot age dataset
    - :floppy_disk: ***Koordinaten.xlsx*** is coordinates dataset 
  
- :open_file_folder: ***1_processed*** contains the results of each analysis step organised in folders
